PROJECTS AND INTERESTS

Hand made PNG decompressor and ASCII renderer

project

I made my own PNG decompression algorithm, for which i had to learn all about gzip compression and dynamic huffman trees. The project decompresses the PNG image into a set of hex values representing the RGB values and then renders the image in a console by typing out different ascii signs depending on the luminance of the pixel.
